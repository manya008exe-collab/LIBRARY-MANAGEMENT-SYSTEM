# Library Management System

## 1. Problem Statement

Managing books manually can be difficult when there are many books in a library. It can take time to find a book and check whether it is available or already issued. There is a need for a simple system that can manage basic book-related tasks easily.

This project provides a simple Python-based system for adding, searching, issuing, returning, and viewing books.

## 2. Scope of the Project

The project is made for basic library book management. It can be used to:

- Add new books.
- Search for books by title or author.
- Check available books.
- Issue books to students.
- Return issued books.
- View all books and their status.

The project currently stores the book data only while the program is running. It does not use a database or permanent file storage.

## 3. Target Users

The main users of this project are:

- Students
- Librarians
- Small libraries
- People learning basic Python programming

## 4. High-Level Features

- Add Book
- Search Book
- Display Available Books
- Issue Book
- Return Book
- Display All Books
- Simple menu-based interface
- Basic messages for invalid choices and book status
